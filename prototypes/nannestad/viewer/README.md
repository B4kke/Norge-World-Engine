# Historical Nannestad viewer harnesses

Forsøk 6 (Stable Viewer Harness) and Forsøk 7 (One-file HD Imagery) are retained in Google Drive/reference storage as historical experiments and were intentionally not copied into the initial GitHub connector bootstrap because they are large self-contained HTML artifacts and are not required by CI or the next P0 correctness work.

Do not treat those files as production source-of-truth. New measurable viewer implementation belongs under `apps/world-viewer/` and should load compiled artifacts through the repository-defined runtime boundary.
