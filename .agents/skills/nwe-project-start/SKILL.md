# NWE Project Start

Before work, read `README.md`, `docs/03-roadmap.md`, `docs/04-decisions.md`, `docs/05-worklog.md`, and `docs/06-task-queue.md` in that order. Pick the highest-value unresolved P0 task that can produce concrete evidence now.

Verify current APIs, package versions, standards, licenses and geodata against primary sources before relying on them. Prefer small reversible changes. Experiments belong in `prototypes/`; production-direction code belongs in `engine/` only after its contract and regressions pass.

Validate with the narrowest relevant tests/build/benchmark. A plausible visualization is not proof. Update worklog and task queue before handoff; update decisions only when a decision actually changes.

End with **Gjort / Bevist / Endret / Neste**.
